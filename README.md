# Bestsellers Dataset Analysis (2009–2019)

## About This Project
This project analyzes and visualizes a dataset of bestselling books from 2009 to 2019. It aims to uncover patterns, trends, and insights about book popularity, genre distribution, author influence, ratings, and pricing. All visualizations are interactive using **Plotly**.

**Key Objectives:**
- Explore overall and yearly genre distribution.
- Identify top authors by genre and total appearances.
- Highlight highest-rated books in each genre.
- Analyze pricing trends (most and least expensive books).

---

## Dataset
The dataset `bestsellers_with_categories.csv` includes the following columns:

| Column       | Description                       |
|--------------|-----------------------------------|
| Name         | Book title                        |
| Author       | Author name                       |
| Genre        | Fiction or Non-Fiction            |
| User Rating  | Average user rating               |
| Reviews      | Number of user reviews            |
| Price        | Book price in USD                 |
| Year         | Year of publication               |
